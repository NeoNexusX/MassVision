# 导航

本文介绍导航组件的使用。

作者：陈柯江

问题反馈：如果在使用 SpatialXomics 或阅读文档时发现问题，可通过 [GitHub Issue](https://github.com/NeoNexusX/MassVision/issues) 提交反馈，或联系邮箱：**jydong@xmu.edu.cn**。



## 操作说明

### 1. 导航栏

处于网页最上面，分为`Home`|`Datahub`|`Workspace`|`Documentation`四个核心区块，用户可根据需求跳转页面，进行使用。其中 `Datahub` 下含公开数据集、我的数据集和数据集合，`Workspace` 下含工作台和新建分析。

右上角头像菜单提供 `Profile`、`Users`（仅管理员）和 `Sign out`；未登录时显示 `Sign in` 与 `Create account`。

![image-20260914202606179](https://official-oss.oss-cn-hongkong.aliyuncs.com/docs/20260914202606293.jpg_view)



### 2. 导航球

首页、登录、注册与数据集可视化等页面不显示顶部导航栏，此时页面右下角会显示一个导航球供用户使用（主要使用场景在数据集可视化功能）。

![image-20260909175034077](https://official-oss.oss-cn-hongkong.aliyuncs.com/docs/20260909175034159.jpg_view)

点击右下角导航球，会在页面左侧出现抽屉式导航供用户进行功能跳转。抽屉内容与前文导航栏基本一致，但有两点差异：抽屉不提供登录/注册入口——未登录用户请通过首页的 `Join to start` 按钮登录或注册；退出登录由导航球上的按钮承担，不在抽屉中。

![image-20260909175259012](https://official-oss.oss-cn-hongkong.aliyuncs.com/docs/20260909175259094.jpg_view)

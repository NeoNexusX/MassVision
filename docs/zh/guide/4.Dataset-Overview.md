# 数据集基本信息查看

本文介绍SpatialXomics中数据集详情页的基本信息构成，以及如何下载原始数据、生成并复制公开分享链接。

作者：陈柯江

问题反馈：如果在使用 SpatialXomics 或阅读文档时发现问题，可通过github issue提交反馈，或联系邮箱：**jydong@xmu.edu.cn**。



## 操作说明

### 1.进入数据基本信息页面

点击所需查看的数据集即可进入基本信息页面。

![image-20260908164356627](https://official-oss.oss-cn-hongkong.aliyuncs.com/docs/20260908164356724.jpg_view)

| 字段                    | 信息                                    | 中文解读                                          |
| ----------------------- | --------------------------------------- | ------------------------------------------------- |

| **Organism Part**       | Brain                                   | 组织/器官部位：**大脑**                           |
| **Condition**           | Control                                 | 实验条件：**对照组**（未处理/正常样本）           |
| **Growth Conditions**   | —                                       | 生长条件：**未填写**                              |
| **Stabilization**       | Ffpe (formalin-fixed paraffin-embedded) | 固定保存方式：**福尔马林固定 + 石蜡包埋**（FFPE） |
| **Tissue Modification** | —                                       | 组织修饰：**未填写**                              |



#### 2.2 MSI Analysis Settings

该部分罗列了质谱成像分析设置。

![image-20260914194545811](https://official-oss.oss-cn-hongkong.aliyuncs.com/docs/20260914194545854.jpg_view)

解读如下：

| 字段                   | 信息                            | 中文解读                                     |
| ---------------------- | ------------------------------- | -------------------------------------------- |
| **Polarity**           | Positive                        | 离子极性：**正离子模式**                     |
| **Ionisation Source**  | MALDI                           | 离子源：**基质辅助激光解吸电离**             |
| **Analyzer**           | Orbitrap                        | 质量分析器：**轨道阱（Orbitrap）**           |
| **Pixel Size**         | 30 × 30 μm                      | 空间分辨率：**30 × 30 微米**                 |
| **Resolving Power**    | at m/z 0, 0                     | 未填写时该行可能显示为 `at m/z 0, 0`，属正常 |
| **Matrix**             | Dhb (2,5-dihydroxybenzoic acid) | 基质：**DHB（2,5-二羟基苯甲酸）**            |
| **Matrix Application** | Spraying                        | 基质涂布方式：**喷雾法**                     |
| **Solvent**            | 100% water                      | 溶剂：**100% 纯水**                          |

### 3.下载数据集

数据集下载有两种方式，

方式一：搜索页面直接点击数据集右侧`Download`进行下载；

![image-20260908170252900](https://official-oss.oss-cn-hongkong.aliyuncs.com/docs/20260908170252957.jpg_view)

方式二：进入基本信息页面点击`Download`进行下载。

![image-20260914195006521](https://official-oss.oss-cn-hongkong.aliyuncs.com/docs/20260914195006583.jpg_view)




### 4.分享数据集链接

数据集链接分享与下载略有不同，需进入基本信息页面再点击`Share`进行链接复制分享。

![image-20260914195044109](https://official-oss.oss-cn-hongkong.aliyuncs.com/docs/20260914195044165.jpg_view)

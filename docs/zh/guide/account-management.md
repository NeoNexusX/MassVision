# 账户管理

本文介绍SpatialXomics的账户注册、登录、找回密码、个人资料管理，以及面向管理员的用户管理。

作者：陈柯江

问题反馈：如果在使用 SpatialXomics 或阅读文档时发现问题，可通过 [GitHub Issue](https://github.com/NeoNexusX/MassVision/issues) 提交反馈，或联系邮箱：**jydong@xmu.edu.cn**。



## 操作说明

### 1. 注册

填写用户名、邮箱、密码与确认密码，点击`Send Code`接收验证码，再补全机构、职位、地区、研究领域等基本信息，完成注册。

注意：用户名、邮箱、密码、确认密码四项须先填写正确才能发送验证码；机构、职位、地区、研究领域为必填项，ORCID 与个人主页为选填项。

![image-20260908150833129](https://official-oss.oss-cn-hongkong.aliyuncs.com/docs/20260908150833177.jpg_view)



### 2. 登录

用户注册完毕后，根据注册的用户名和密码，完成登录。

![image-20260908151359943](https://official-oss.oss-cn-hongkong.aliyuncs.com/docs/20260908151359974.jpg_view)



### 3. 账户管理

点击页面右上角头像后点击 `Profile` 即可进入账户管理页面，功能包括更改邮箱、更改密码等，除用户名和身份（Identity）外其余信息均可修改，修改后点击 `Save All Changes`进行保存。

更改邮箱时需向新邮箱发送验证码并填写后提交；更改密码保存后会自动退出登录，需使用新密码重新登录。

![账户管理页面](https://official-oss.oss-cn-hongkong.aliyuncs.com/docs/20260908160212186.jpg_view)



### 4. 配额管理

该部分显示账户配额的使用情况，四张卡片均以“已用/上限”形式显示并附进度条：**Storage Upload**（上传存储）、**Files**（文件数）、**Processing**（处理量）、**Downloads**（下载次数）。

![image-20260908160325414](https://official-oss.oss-cn-hongkong.aliyuncs.com/docs/20260908160325443.jpg_view)



### 5. 找回密码

忘记密码时，在登录页面点击`Forgot Password?`进入找回密码页面，流程分两步：

1. 输入注册邮箱，点击`Send Code`接收验证码；未收到可点击`Resend`重发，邮箱填错可点击`Change email`更换。
2. 输入验证码与新密码（需输入两遍确认），点击`Reset Password`完成修改，随后用新密码重新登录。

<!-- 图片位置：找回密码两步流程截图 -->



### 6. 用户管理（仅管理员）

管理员点击右上角头像菜单中的`Users`进入用户管理页面；非管理员访问该页面会被重定向到个人资料页。页面功能包括：

- **统计卡片**：管理员数、用户数、机构数；
- **查找用户**：按用户名搜索，按状态（Active / Inactive）、机构、地区筛选；
- **用户表格**：用户名、身份（admin / user）、状态、机构、地区、查看；
- **详情抽屉**：点击`View`查看用户基本信息与当前用量，并可就地编辑、保存该用户的配额（文件数 / 上传存储 / 处理量 / 下载次数）；
- **删除用户**：仅可删除非管理员且非本人的用户，确认后删除。

注意：身份（admin / user）为只读展示，页面不提供修改角色或启用/禁用账号的操作。

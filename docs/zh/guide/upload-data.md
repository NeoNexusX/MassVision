# 上传数据

本页介绍如何将质谱成像（MSI）数据上传到 SpatialXomics。

## 支持的格式

- **imzML 数据对**：`.imzML`（元数据/谱图索引）+ `.ibd`（二进制谱图数据），两个文件必须**同名**（仅扩展名不同），否则无法配对上传。

## 操作步骤

1. 在数据集页面点击 **上传** 按钮，打开上传弹窗。
2. 选择本地的 `.imzML` 与 `.ibd` 文件对（或拖拽），并填写数据集元信息（如分析仪类型、离子源、像素大小等）。
3. 浏览器会先对文件做哈希计算，再压缩打包成 ZIP——这一步在 Web Worker 中进行，不会卡住页面，压缩产物会暂存于浏览器的 OPFS（Origin Private File System）中以支持续传。
4. 客户端向后端申请阿里云 OSS 的临时上传凭证，随后以**分片上传**的方式将压缩包传到 OSS；如果后端通过哈希识别出文件已存在，会直接复用，无需重新上传。
5. 上传完成后，数据集会出现在数据面板中，状态变为可分析。

## 续传与重试

- 上传过程中的分片进度（uploadId、已完成分片、凭证有效期）会写入本地存储；如果中途关闭页面或网络中断，重新打开上传弹窗会看到 **续传提示**，点击即可从断点继续，无需重新压缩或重新计算哈希。
- 单个分片上传失败会自动重试，仍失败才会提示用户处理。

## 小贴士

- 上传前请确认 `.imzML` 与 `.ibd` 文件名（不含扩展名）完全一致。
- 大文件的哈希计算和压缩在后台进行，期间可以继续浏览其他页面。
- 如果上传失败，优先检查文件名是否匹配、网络是否稳定，再尝试使用续传功能重新发起。



# 数据可视化

本文介绍SpatialXomics中数据集离子图、TIC 图与质谱图的查看方式，涵盖 UMAP/KMeans 聚类、ROI 圈选、区域比较与注释匹配等空间分析操作。

## 操作说明

### 1.数据集状态区分

数据集封面主要会呈现两种形式：“Explore” 和 “Visualize”。

![image-20260909211924082](https://official-oss.oss-cn-hongkong.aliyuncs.com/docs/20260909211924161.jpg_view)

当数据集处在”Explore“时，此时数据集还在待处理阶段，还无法查看可视化结果，需点击`Explore`后再选择`Generate`创建数据预处理任务，创建成功后，将自动跳转至Workspace页面，页面具体信息见[工作区](./8.Workspace)。

![image-20260909212549202](https://official-oss.oss-cn-hongkong.aliyuncs.com/docs/20260909212549240.jpg_view)

当数据集处在“Visualize”时，此时数据集已经过预处理，点击`Visualize`即可跳转至数据可视化页面，直接查看可视化结果。



### 2.可视化页面简介

可视化页面可主要分为离子强度图、像素谱图、区域比较栏、基本信息栏、注释面板五个功能模块。后文将对以上五个模块功能详细介绍。

![image-20260911150203224](https://official-oss.oss-cn-hongkong.aliyuncs.com/docs/20260911150203309.jpg_view)

#### 2.1基本信息栏

**1.Info（信息）**

显示数据集元数据：Polarity（极性）、Analyzer（质量分析器）、Ionisation Source（离子源）、Pixel Size（像素尺寸）、Spectrum Mode（谱图模式）、Storage Mode（imzml存储模式）。

**2. Display Range（显示范围）**

- 直接输入 Min/Max 数值
- 实时显示当前值对应的**百分位**（如 "95.23%")

**3. Statistic（统计）**

- **强度直方图**：可视化强度分布，红线标记当前 Min/Max
- **Dimensions**：图像尺寸（如 100 × 80)
- **Non-zero**：非零像素数量
- **TIC**：总离子流

**4. Preprocessing（预处理）**

显示该结果使用的处理方法列表，如 "Direct conversion (no preprocessing)"

**5. Visualization（可视化控件）**

- Gamma 校正：
  - 滑块范围 0.5–1.5，默认 1.0
  - 调整图像亮度/对比度曲线
- UMAP / KMeans 降维聚类（仅 Continuous 模式）

| 功能                   | 说明                                                  |
| ---------------------- | ----------------------------------------------------- |
| **Enable UMAP/KMeans** | 首次开启需确认，后端创建 UMAP 计算任务                |
| **UMAP**               | 显示 UMAP 降维嵌入的二维分布覆盖层                    |
| **KMeans**             | 在 UMAP 基础上做 KMeans 聚类（k=2–20)，本地浏览器计算 |
| **Opacity**            | 分别调节 UMAP/KMeans 覆盖层透明度                     |
| **Export PNG**         | 导出 UMAP/KMeans 图像                                 |
| **Cluster 筛选**       | 勾选/取消特定 cluster，控制显示范围                   |

**6. Region of Interest(ROI)**

| 功能                    | 说明                                       |
| ----------------------- | ------------------------------------------ |
| **Rect**                | 拖拽绘制矩形 ROI                           |
| **Lasso**               | 自由绘制不规则 ROI                         |
| **Confirm/Cancel**      | 确认或取消当前草稿                         |
| **ROI only / Show all** | 切换：只显示 ROI 区域 或 显示完整图像      |
| **ROI 统计**            | 每个 ROI 显示：Pixels、Mean、Std、Min、Max |
| **管理**                | 删除单个 ROI 或 Clear all                  |



#### 2.2离子强度图

显示选中 m/z 的离子在空间上的强度分布热图。

![image-20260911153144224](https://official-oss.oss-cn-hongkong.aliyuncs.com/docs/20260911153144287.jpg_view)

**1.图像交互**

| 功能         | 说明                                                         |
| ------------ | ------------------------------------------------------------ |
| **缩放**     | 鼠标滚轮在离子图区域以指针位置为中心缩放；右下 `− / 倍率 / +` 按钮 |
| **平移**     | 放大后按住左键拖动                                           |
| **像素信息** | 悬停显示 1-based 坐标 `(x, y)` 和强度值                      |
| **像素选择** | Processed 模式下点击像素可加载该像素的完整谱图               |

**2. 工具栏控件**

| 控件                | 说明                                                         |
| ------------------- | ------------------------------------------------------------ |
| **m/z 搜索**        | 仅 Continuous 模式可用，输入目标 m/z，点击 Search 或回车跳转最近峰 |
| **Tolerance ±**     | m/z 容差（默认 0.0001，范围 1e-8 – 1)，控制峰匹配的宽容度    |
| **Colormap**        | 5 种配色：Viridis、Inferno（默认）、Magma、Hot、Gray         |
| **Intensity Scale** | Linear / Log / TIC norm（连续模式且有预计算 stats/tic 时可用） |
| **Reset**           | 一键恢复所有控件到默认值                                     |
| **PNG**             | 导出当前图像为透明背景 PNG                                   |

**3. 强度调节（右侧条）**

- **Display Range 滑块**：拖动调整 Min/Max，改变对比度
- **Gamma 校正**：右侧滑块，范围 0.5–1.5，默认 1.0



#### 2.3像素谱图

根据数据模式显示不同内容：

| 模式           | 显示内容           | 交互                                                     |
| -------------- | ------------------ | -------------------------------------------------------- |
| **Continuous** | 整个数据集的平均谱 | 点击谱图任意位置 → 切换到最接近的 m/z 并刷新离子强度图像 |
| **Processed**  | 选中像素的单点谱   | 先在 TIC 图上点击像素 → 加载该像素谱                     |

- Centroid 数据显示为**柱状峰**
- Profile 数据显示为**连续曲线**
- 当前选中 m/z 用**竖线高亮**
- 底部显示统计：Peaks、Intensity、Selected/Tolerance 或 Pixel



#### 2.4区域比较

**仅 Centroid 数据可用**，用于比较两个区域（A vs B）的谱图差异。主要有两类数据来源，KMeans 聚类产生的 clusters或用户绘制的 ROIs，现就以上两类数据比较做一流程介绍。

##### 2.4.1 KMeans 聚类产生的 clusters

![image-20260914160650389](https://official-oss.oss-cn-hongkong.aliyuncs.com/docs/20260914160650461.jpg_view)

2.选择聚类层数得到聚类结果

![image-20260914160834734](https://official-oss.oss-cn-hongkong.aliyuncs.com/docs/20260914160834781.jpg_view)

![image-20260914160853610](https://official-oss.oss-cn-hongkong.aliyuncs.com/docs/20260914160853673.jpg_view)

2.点击`ROI only`后回到初始状态，再进行一遍第一步操作，得到感兴趣的ROI2

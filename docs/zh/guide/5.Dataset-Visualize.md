# 数据可视化

本文介绍SpatialXomics中数据集离子图、TIC 图与质谱图的查看方式，涵盖 UMAP/KMeans 聚类、ROI 圈选、区域比较与注释匹配等空间分析操作。

作者：陈柯江

问题反馈：如果在使用 SpatialXomics 或阅读文档时发现问题，可通过 [GitHub Issue](https://github.com/NeoNexusX/MassVision/issues) 提交反馈，或联系邮箱：**jydong@xmu.edu.cn**。



## 操作说明

### 1. 数据集状态区分

数据集封面主要会呈现两种形式：“Explore” 和 “Visualize”。

![image-20260909211924082](https://official-oss.oss-cn-hongkong.aliyuncs.com/docs/20260909211924161.jpg_view)

当数据集处在”Explore“时，此时数据集还在待处理阶段，还无法查看可视化结果，需点击`Explore`后再选择`Generate`创建数据预处理任务，创建成功后，将自动跳转至Workspace页面，页面具体信息见[工作区](./8.Workspace)。

![image-20260909212549202](https://official-oss.oss-cn-hongkong.aliyuncs.com/docs/20260909212549240.jpg_view)

当数据集处在“Visualize”时，此时数据集已经过预处理，点击`Visualize`即可跳转至数据可视化页面，直接查看可视化结果。



### 2. 可视化页面简介

可视化页面可主要分为离子强度图、像素谱图、区域比较栏、基本信息栏、注释面板五个功能模块。后文将对以上五个模块功能详细介绍。

![image-20260911150203224](https://official-oss.oss-cn-hongkong.aliyuncs.com/docs/20260911150203309.jpg_view)

#### 2.1 基本信息栏

**1.Info（信息）**

显示数据集元数据：Polarity（极性）、Analyzer（质量分析器）、Ionisation Source（离子源）、Pixel Size（像素尺寸）、Spectrum Mode（谱图模式）、Storage Mode（imzml存储模式）。

**2. Display Range（显示范围）**

- 直接输入 Min/Max 数值
- 实时显示当前值对应的**百分位**（如 "95.23%")

**3. Statistic（统计）**

- **强度直方图**：可视化强度分布，红线标记当前 Min/Max
- **Dimensions**：图像尺寸（如 100 × 80)
- **Non-zero**：非零像素数量
- **TIC**：总离子流

**4. Preprocessing（预处理）**

显示该结果使用的处理方法列表，如 "Direct conversion (no preprocessing)"

**5. Visualization（可视化控件）**

- Gamma 校正：
  - 滑块范围 0.5–1.5，默认 1.0
  - 调整图像亮度/对比度曲线
- UMAP / KMeans 降维聚类（仅 Continuous 模式）

| 功能                   | 说明                                                  |
| ---------------------- | ----------------------------------------------------- |
| **Enable UMAP/KMeans** | 首次开启需确认，后端创建 UMAP 计算任务                |
| **UMAP**               | 显示 UMAP 降维嵌入的二维分布覆盖层                    |
| **KMeans**             | 在 UMAP 基础上做 KMeans 聚类（k=2–20)，本地浏览器计算 |
| **Opacity**            | 分别调节 UMAP/KMeans 覆盖层透明度                     |
| **Export PNG**         | 导出 UMAP/KMeans 图像                                 |
| **Cluster 筛选**       | 勾选/取消特定 cluster，控制显示范围                   |

**6. Region of Interest(ROI)**

| 功能                    | 说明                                       |
| ----------------------- | ------------------------------------------ |
| **Rect**                | 拖拽绘制矩形 ROI                           |
| **Lasso**               | 自由绘制不规则 ROI                         |
| **Confirm/Cancel**      | 确认或取消当前草稿                         |
| **ROI only / Show all** | 切换：只显示 ROI 区域 或 显示完整图像      |
| **ROI 统计**            | 每个 ROI 显示：Pixels、Mean、Std、Min、Max |
| **管理**                | 删除单个 ROI 或 Clear all                  |



#### 2.2 离子强度图

显示选中 m/z 的离子在空间上的强度分布热图。

![image-20260911153144224](https://official-oss.oss-cn-hongkong.aliyuncs.com/docs/20260911153144287.jpg_view)

**1.图像交互**

| 功能         | 说明                                                         |
| ------------ | ------------------------------------------------------------ |
| **缩放**     | 鼠标滚轮在离子图区域以指针位置为中心缩放；右下 `− / 倍率 / +` 按钮 |
| **平移**     | 放大后按住左键拖动                                           |
| **像素信息** | 悬停显示 1-based 坐标 `(x, y)` 和强度值                      |
| **像素选择** | Processed 模式下点击像素可加载该像素的完整谱图               |

**2. 工具栏控件**

| 控件                | 说明                                                         |
| ------------------- | ------------------------------------------------------------ |
| **m/z 搜索**        | 仅 Continuous 模式可用，输入目标 m/z，点击 Search 或回车跳转最近峰 |
| **Tolerance ±**     | m/z 容差（默认 0.0001，范围 1e-8 – 1)，控制峰匹配的宽容度    |
| **Colormap**        | 5 种配色：Viridis、Inferno（默认）、Magma、Hot、Gray         |
| **Intensity Scale** | Linear / Log / TIC norm（连续模式且有预计算 stats/tic 时可用） |
| **Reset**           | 一键恢复所有控件到默认值                                     |
| **PNG**             | 导出当前图像为透明背景 PNG                                   |

**3. 强度调节（右侧条）**

- **Display Range 滑块**：拖动调整 Min/Max，改变对比度
- **Gamma 校正**：右侧滑块，范围 0.5–1.5，默认 1.0



#### 2.3 像素谱图

根据数据模式显示不同内容：

| 模式           | 显示内容           | 交互                                                     |
| -------------- | ------------------ | -------------------------------------------------------- |
| **Continuous** | 整个数据集的平均谱 | 点击谱图任意位置 → 切换到最接近的 m/z 并刷新离子强度图像 |
| **Processed**  | 选中像素的单点谱   | 先在 TIC 图上点击像素 → 加载该像素谱                     |

- Centroid 数据显示为**柱状峰**
- Profile 数据显示为**连续曲线**
- 当前选中 m/z 用**竖线高亮**
- 底部显示统计：Peaks、Intensity、Selected/Tolerance 或 Pixel

#### 2.5 注释面板

注释面板位于可视化页面左侧，可折叠/展开。用于导入外部代谢物/脂质注释 CSV 表，将每行的实验 m/z 与当前平均谱匹配，并支持跳转、筛选、导出和 PubChem 查询。

::: warning 前提条件
注释匹配仅适用于 **Continuous + Centroid** 数据。Profile 模式下该面板会显示警告提示。
:::

**1. 导入 CSV**

点击 **Import CSV** 选择文件，或将 CSV 文件直接拖放到面板区域。解析在 Web Worker 中执行，大表格使用虚拟滚动避免卡顿。

CSV 格式要求：
- 编码支持 UTF-8 和 UTF-8 BOM；分隔符自动检测（逗号、分号、Tab、`|`）。
- 必须包含 m/z 列，识别列名：`Exp. m/z`、`Tar. m/z`、`mz`、`m/z`、`experimental_mz`、`mass` 等。
- 候选化合物名从 `Candidate_1` 到 `Candidate_N`（或单个 `Candidate` 列）合并。
- 可选列：`formula_ion` / `formula`（分子式）、`Ion type` / `adduct`（加合物类型）。

**2. 匹配容差**

- 支持 **ppm** 和 **Da** 两种单位，通过下拉菜单切换。
- 输入容差数值后自动重新匹配。

**3. 筛选与搜索**

- 顶部计数徽章可按 **All / Matched / Unmatched** 快速筛选。
- 支持按 **Adduct（加合物）** 和 **Formula（分子式）** 下拉筛选。
- 搜索框支持按名称、分子式或 m/z 值关键词搜索。

**4. 排序**

在 **Sort by** 下拉中可按以下字段排序，点击右侧箭头切换升序/降序：
- Name（名称）
- Exp. m/z（目标 m/z）
- Mass Difference（质量差）
- Intensity（强度）
- Composite score（综合证据分，见下，高分在前）
- Adduct score（多加合物加分，见 4a，高分在前）
- FDR（target-decoy q 值，小者在前）

**4a. 证据评分（Level 5 → Level 4）**

仅靠精确质量匹配对应 MSI 置信体系的 **Level 5**（只有质量）。当 CSV 提供 `formula_ion` 时，每条匹配行会额外获得完全在浏览器端计算的证据分：

- **质量分**：质量误差在容差内的线性衰减。
- **同位素分**：按离子式即时计算理论同位素包络（自然丰度卷积），用 pySM `isotope_pattern_match` 的公式（L2 归一后的 L1 距离）与平均谱实测峰强比较。注意该谱图分本身判别力偏弱——参考实现的区分主要靠下面的图像度量。
- **综合分**：质量分 × 同位素分。分子式不可解析的行优雅降级（按中性常数折算，排在一切有分值行之下）。
- **FDR（q 值）**：pySM 式 target-decoy 估计——同一套打分管线跑在化学上不可能出现的 decoy 加合物（如 [M+Mn]⁺）上，由 decoy 分数分布得出每行的经验假发现率，越小越可信。
- **置信等级**：`L4`（精确质量 + 同位素支持：同位素分 ≥ 0.9 **且**期望同位素峰全部观测到）或 `L5`（仅精确质量），以徽章显示在行内。
- **多加合物加分（adductScore）**：同一中性分子以 ≥2 种加合物离子成组检出（如 [M+H]⁺ 与 [M+Na]⁺ 同时命中）时，按 CAMERA 加合物规则表为组计分——准分子离子（[M+H]⁺/[M−H]⁻ 等）ips=1.0，碱金属替代（[M−2H+Na]⁻ 等）ips=0.5，`adductScore = min(1, (Σips−1)/2)`，综合分再乘 `1 + 0.2·adductScore`。加分在 FDR 之后应用（q 值仍基于未加成口径，因 decoy 金属加合物无法成组）。成组行在表格中带 **M×n** 徽章，悬停卡内可跳转组成员。

**L4 筛选 chip** 可将表格限制为 Level 4 行。

**4b. 空间证据（pySM MSM 度量）**

对综合分前 200 行，面板渐进加载理论同位素峰（最多 4 个）的离子图像，计算 pySM（Palmer et al., *Nat Methods* 2017）的三个度量，按 **MSM = chaos × spatial × spectral** 相乘：

- **Chaos（ρ_chaos，level-sets 空间混沌度）**：图像按 10 个强度层阈值化，每层先十字膨胀再 3×3 腐蚀后数 4-连通域；结构化单区域保持低计数（→1），散点碎片被否决（→0）。
- **Spatial（ρ_spatial，同位素图像相关）**：单同位素峰图像与各卫星同位素图像的加权 Pearson（权重 = 理论强度），clip 到 [0,1]。同一分子的离子必须共定位；卫星图像零相关是强反证。
- **Spectral（ρ_spectral，图像强度模式）**：各同位素图像在 M 掩码上的总强度 vs 理论包络，L2 归一 L1 距离。

打分前图像先做 p99 热点裁剪（pySM 预处理）。悬停某行或滚动列表会把该行提到打分队列最前。度量显示在悬停卡与导出 CSV 中，且**有意不**回馈进 Tier-1 综合分（它负责全量行集的排序）。

**多加合物空间确认**：进入 Top-K 的加合物组会另加载各成员的 M 图像做两两 Pearson 相关，每行显示与组内其他成员的最大相关 `r`。与上面三个 MSM 度量不同，该确认**会**回馈排序：按 `r ≥ 0.7` 边的连通分量判定（分量须含 ≥2 种不同加合形式且含准分子离子，对齐 adduct_filter 的确认步骤）——通过的分量保留 Tier-1.5 加成并标记已确认；未通过的分量撤销加成（综合分除回、`adductScore` 清零、面板随之重排，徽章转警告色、导出列以 `adductUnconfirmed` 标注）。

**5. 表格交互**

- 表格显示两列：**Annotation**（注释名 + 置信徽章）和 **Exp. m/z**（实验 m/z）。
- 悬停行显示详细信息卡片：匹配 m/z、质量差、平均强度，主区只展示关键评分（综合分、置信等级、FDR、MSM 及其就绪进度），质量/同位素/加合物/混沌度/共定位等明细折叠进"详细评分"；另提供 **同位素峰跳转** 按钮（M+1、M+2…，按理论同位素包络跳转最近谱峰）、**多加合物组** 徽章（M×n，点击组内 chip 选中对应行）和 PubChem 查询按钮。
- 点击已匹配行跳转到对应 m/z，刷新离子图并高亮谱图峰。

**6. 导出与清除**

- 点击下载按钮导出已匹配行的 CSV，包含证据分列；空间评分已运行时附 Chaos/Coloc 列，多加合物成组时另附 Adduct Score / Adduct Peers / Adduct Corr 列。
- 点击垃圾桶按钮清除导入数据。
